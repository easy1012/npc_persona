# 헤이즐 마을 플레이어 수첩 UI 개선 설계

## 목표

현재의 `마을 통신 수첩` 메타포를 유지하면서, 플레이어가 NPC·현재 목표·대화·의뢰 진행 상태를 한눈에 파악할 수 있는 판타지 RPG 인터페이스로 개선한다.

## 수정 경계

- 수정: `player_app.py`의 표시용 HTML, `journal_showcase_styles.css`, `player_components.py`의 브라우저 표시와 키보드 탐색
- 유지: API 호출, 세션 상태, NPC 선택 처리, 퀘스트 진행 처리, 메시지 전송, 모델·DB·배포 코드

## 시각 방향

- 제품 메타포: 모험가가 들고 다니는 마을 통신 수첩
- 기억점: NPC는 왁스 인장, 현재 목표는 지도 리본, 의뢰 상태는 수첩 탭처럼 보인다.
- 분위기: 따뜻한 양피지, 짙은 목재, 이끼색과 꿀색 포인트를 사용한다.
- 정보 밀도: 장식보다 대화와 목표를 우선하며, 모든 장식은 정보 계층을 강화하는 역할만 맡는다.

## 화면 구조

1. 상단 상태 바: 현재 NPC, NPC 역할, 현재 목표, 온라인 수첩 상태를 표시한다.
2. NPC 명단: 인장형 카드로 NPC와 의뢰를 표시하고 현재 선택 상태를 명확히 구분한다.
3. 대화 기록: NPC와 플레이어의 메시지를 서로 다른 종이 형태와 정렬로 구분한다.
4. 의뢰 수첩: 의뢰별 진행 상태와 힌트 단계를 단계 표식으로 표시한다.
5. 입력 영역: 현재 대화 상대와 전송 동작을 설명하는 입력 안내를 제공한다.

## 상태 및 접근성

- 상태는 색상뿐 아니라 문구, 도형, 테두리 패턴으로 중복 표현한다.
- 모든 조작 대상은 최소 44px 높이와 명확한 `:focus-visible` 표시를 갖는다.
- 모바일 순서는 NPC → 상태 → 대화 → 의뢰 → 입력이다.
- 375px, 768px, 1280px에서 가로 스크롤 없이 동작해야 한다.
- `prefers-reduced-motion`에서는 장식 애니메이션을 제거한다.

## 검증 기준

- 기존 API·세션·메시지 전송 코드의 의미가 변하지 않는다.
- 정적 UI 계약 테스트가 통과한다.
- 실제 브라우저에서 데스크톱과 모바일 레이아웃, 키보드 포커스, NPC 선택을 확인한다.
- 한국어 긴 문장이 카드 밖으로 넘치지 않는다.
